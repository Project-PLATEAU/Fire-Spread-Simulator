# 火災延焼シミュレーションシステム（ファイル作成ツール/条件設定支援ツール）



「火災延焼シミュレーションシステム」は、PLATEAUの3D都市モデルを活用し、風向・風速などの与条件や任意の出火点を指定し、市街地の延焼拡大予測を建物一棟単位で行うためのシステムです。

本業務では、火災延焼シミュレーションシステムの周辺ツールとして「ファイル作成ツール」「条件設定支援ツール」を開発しました。

- ファイル作成ツール：3D都市モデル（建築物）CityGML形式を「条件設定支援ツール」、「エンジン」で使用するためのデータに変換する
- 条件支援設定ツール：GUIを用いてエンジンを実行するための条件（風向・風速・出火点など）を設定する
